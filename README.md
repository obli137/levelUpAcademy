# levelUp Academy · sitio

Sitio estático de levelUp Academy.

## Publicar en GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí todo el contenido de esta carpeta a la raíz del repositorio (incluido `.nojekyll`).
3. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
4. A los pocos minutos el sitio queda en `https://<usuario>.github.io/<repositorio>/`.

## Pendiente antes de publicar

- Completar los datos marcados en amarillo entre corchetes.
- Las URLs canónicas y las de `llms.txt` apuntan a `https://www.hrlevel-up.com/formacion/...`. Ajustarlas al dominio definitivo.
- El contenido se arma en el navegador. Para SEO, convertir las páginas a HTML estático.
